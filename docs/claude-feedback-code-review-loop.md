После каждой задачи прогоняй `code-reviewer` agent **в цикле**, не один раз. Когда ревьюер находит замечания — исправляй и **снова** запускай ревьюер. Повторяй пока ревьюер не вернёт чистый отчёт с 0 нарушений (и важных, и косметических). Только после этого задача считается готовой к сдаче пользователю.

**Why:** Дмитрий явно попросил это после того как я в задаче «Карточка товара» прогнал ревью один раз, исправил замечания, но не перепроверил — а в требованиях на качество уровня dorogix компаний должна быть гарантия что после правок всё чисто. Один прогон не гарантирует что правки не внесли новых проблем.

**How to apply:**
- После имплементации фичи → запустить `code-reviewer` agent
- Если **есть замечания** (любого уровня — important / minor / cosmetic) → исправить → **снова** прогнать `code-reviewer`
- Если **0 замечаний** → коммит → отчёт пользователю «готово»
- Не пропускать «минорные» замечания между итерациями — они тоже считаются нарушениями
- После исправления первой пачки и нового прогона может всплыть что-то новое (например, я мог что-то сломать своей правкой) — это и есть смысл цикла
